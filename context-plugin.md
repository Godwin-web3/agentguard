# Context Plugin (/context-plugin)

The context plugin teaches your AI coding assistant how to use this API's SDKs, so the code it writes for you calls the API the way the SDKs are meant to be used.

## Install [#install]

```bash
npx context-plugins install "/__downloads/plugin.zip"
```

## What it does [#what-it-does]

Once the plugin is installed, describe what you want to build and your assistant works from the SDK for your language: how to install it and create a client, how to authenticate, and which methods and types to use for each call. You spend less time correcting code written from guesses about the API.

## Supported languages [#supported-languages]

- TypeScript
- Python
- C#

## Supported platforms [#supported-platforms]

- Claude Code
- Cursor
- GitHub Copilot
